# 🛒 Dynamic PHP E-Commerce Platform

A feature-rich e-commerce web application developed using **Vibe Coding & AI-Assisted Engineering**, integrated with native PHP, MySQL, and modern responsive design.

> 🤖 **Vibe Coding Project:** Conceptualized and structured using AI-driven Vibe Coding tools, followed by custom integration of PHP backend logic, database architecture (`schema.sql`), and security practices.

---

## ✨ Key Features

- **Dynamic Product Catalogue:** Automatic discount percentage calculation, out-of-stock overlay badges, and featured product highlights.
- **Cart & Order System:** Smooth checkout process and order tracking system.
- **Admin Dashboard:** Full control over categories, products, and management routines.
- **Security Best Practices:** Input sanitization using `htmlspecialchars()` to prevent XSS attacks.

---

## 🛠️ Tech Stack & Tools

- **Backend:** Native PHP
- **Database:** MySQL / SQLite (`schema.sql`)
- **Frontend:** HTML5, CSS3, JavaScript, FontAwesome Icons
- **Development Approach:** Vibe Coding / AI-Assisted Development

---

## 🚀 How to Run Locally

1. **Clone or Download the repository.**
2. **Move files:** Copy the project folder into your local server (e.g., XAMPP `htdocs`).
3. **Database Setup:**
   - Create a MySQL database via phpMyAdmin.
   - Import `database/schema.sql` into the newly created database.
   - Configure database connection in `includes/db.php` or `.env`.
4. **Launch:** Open your browser and navigate to `http://localhost/PHP-Ecommerce-Platform/index.php`.
